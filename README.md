Prototipo captura precios bol

## Para Claude / IA que retome este proyecto

El backend real de este prototipo (al que `dashboard.html` y `lib/main.dart`
le pegan) **no vive en esta carpeta** — es un port a PHP/CodeIgniter que
está en `C:\Trabajo\azzorti-captura-backend-deploy\php\`. Ahí hay un
archivo `CONTEXTO_SESION.md` con el resumen completo de qué se hizo, qué
se descubrió del servidor real, y qué queda pendiente — leelo antes de
tocar `dashboard.html` o de asumir cómo responde la API. Dato clave: la
persona dueña de este proyecto no tiene experiencia de programación y
sube los archivos al servidor manualmente — un cambio de código local
no se refleja en la API real hasta que ella lo suba.
